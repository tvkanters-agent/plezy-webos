## Plezy webOS 1.1.0 — Alphabetical library navigation

- Plezy's right-edge TV alphabetical navigation rail, with highlighted letters, overscan spacing, D-pad/OK/Back support, pointer gestures and detail-return focus restoration.
- **Plex:** fetches native `firstCharacter` counts and jumps directly by cumulative media offset. Sparse page loading avoids fetching all earlier titles.
- **Jellyfin/Emby:** original distinct `#`–`Z` server-side NameStartsWith/NameLessThan prefix filtering, cleared by reselecting the active letter.
- The rail only appears when supported by the library and sorting state.
- Includes unit/browser regressions; physical LG TV verification remains outstanding.

### Installation

Install `com.tvkdevelopment.plezy_1.1.0_all.ipk` from the release assets; the app upgrades in place. GitHub Actions publishes after tests, Chromium 53 bundle checks and IPK packaging succeed.
