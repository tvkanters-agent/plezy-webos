# Plezy webOS v1.5.6

## Fixed

- Library artwork now begins loading up to three rows ahead of scrolling, and three rows behind the viewport, to reduce empty posters when moving through a large catalog.
- Visible artwork takes priority over speculative off-screen requests. The row buffer adapts to the rendered card dimensions and TV CSS layout, including episode rows.
- Download concurrency remains limited to six. Distant images stay deferred to avoid unnecessary memory and network usage.

## Compatibility

- Preserves the existing webOS 4.x / Chromium 53 frontend and TV D-pad behavior.
- Automated tests cover forward/backward row prefetch; LG TV hardware performance remains unverified.
