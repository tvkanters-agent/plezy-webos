# Plezy webOS v1.5.5

## Improved

- Fetch up to six uncached poster images concurrently instead of two, following Plezy's full-performance artwork request budget.
- Prioritize currently visible library artwork ahead of nearby prefetched cards.
- Preserve first-frame cache reuse, bounded decoding, persistent storage and lazy offscreen loading.

## Compatibility

- Chromium 53 / webOS 4.x compatibility is maintained. Actual TV throughput also depends on the media server, connection limits and network speed.
