# Plezy webOS v1.11.0

Render Plex external subtitles on the television using **Media Captions for SRT** and **SubtitlesOctopus/libass for ASS and SSA**.

- Selected subtitle files follow the active Plex subtitle choice, including track changes and playback resume.
- The existing subtitle sync adjustment applies immediately to both renderers: positive values delay subtitle display.
- SRT captions animate upward when the playback controls open and return when they hide.
- Compatible sources can Direct Play video with external SRT/ASS; no unnecessary video transcoding just to show those subtitles.
- Embedded and unsupported tracks still use Plex's HLS burn-in, and subtitle renderer failures fall back to that path.
- Includes local libass workers and an old-webOS compatibility layer.

LG OLED C8/webOS 4.x hardware verification remains needed for actual ASS worker rendering and Plex sidecar delivery.
