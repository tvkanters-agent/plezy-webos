# Plezy webOS v1.8.2

- **Skip Intro now loads from Plex playback metadata.** The player requests chapter and marker data separately, as the original Plezy app does, so cached or lightweight episode details no longer prevent an available intro prompt from appearing.
- **One-press skip on LG:** When the prompt appears during playback, it receives focus for a single OK press. The player also handles LG's stale decoder-ready state after its `playing` event.
- **Correct chapter gaps:** The seek-bar chapter divisions are now 4px wide, matching Plezy, rather than the accidental 52px gaps caused by an inherited timestamp style.
- Read Plex chapter names from `tag`, including chapter-name detection of intro segments. Playback metadata refreshes without restarting the video.

Automated tests cover a video that starts from marker-free metadata, receives markers and chapters after playback begins, focuses Skip Intro and seeks on a single simulated LG OK press; the chapter-gap width is verified in the browser. Physical LG webOS 4.4.3 playback still requires hardware verification.
