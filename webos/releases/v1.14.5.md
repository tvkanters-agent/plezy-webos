# Plezy webOS 1.14.5

- Fix fallback to burned-in SRT and ASS subtitles on MKV files. Plex only burns the subtitle currently selected on its media part; the previous retry started HLS without ensuring that selection, so video restarted but subtitles could remain absent.
- Follow Plezy's selection-before-decision flow, including for a subtitle implicitly selected by Plex. If the selection request fails, do not start a burn-in session that would silently omit subtitles.
- Keep the existing silent fallback and disabled timing controls for burned-in subtitles.
