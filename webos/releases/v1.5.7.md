# Plezy webOS v1.5.7

- Fast library scrolling loads the visible range directly instead of fetching every intervening page, including when scrolling backward.
- Scrolling entries display as soon as metadata arrives without waiting for artwork disk reads and decoding. Cached page entry preparation is retained.
- Metadata prefetch starts at least three rows before the loaded boundary.
- Regression coverage checks large forward/reverse scrolls in grid and flex layouts, blocked artwork preparation, and changing direction during a delayed request.

Validated with automated browser tests; physical LG TV performance still requires verification.
