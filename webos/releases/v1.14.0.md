# Plezy webOS 1.14.0

- Display Plezy's pre-play video, audio and subtitle status at the right end of the detail action row, with volume/subtitle icons and an explicit **Off** when subtitles are disabled.
- For movies and episodes, use the selected media version and its own source streams. For shows and seasons, preview the episode their Play action would start.
- Reflect pre-play track changes, cross-episode language selection and media-version changes immediately, without opening a stream or moving remote focus.
- Fit the one-line status to the available space by dropping codec details and video labels first; preserve the subtitle decision as long as it fits. Restore its live updates when returning to a cached detail page.

Browser tests check stream selection, multi-version tracks, menu changes, status placement and focus. Real LG TV rendering and decoder behavior still require device verification.
