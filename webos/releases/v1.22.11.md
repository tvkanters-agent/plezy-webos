## Fixes

- Plex Mark watched/unwatched and Rate requests now use the existing 15-second cancellable HTTP transport. XML and empty successful responses remain supported; failed requests are retryable.
- Next Episode no longer stops at the 1,000-item season pagination boundary. Seasons longer than 1,000 episodes are fully scanned, without skipping to the next season prematurely.

## Verification

Automated regression tests cover timeout/HTTP error handling, successful XML and empty responses, retries, large seasons, missing episode numbers, short pages and empty pages. Hardware validation on LG webOS remains outstanding.
