# Plezy webOS v1.5.1

- Decode only visible and nearby library artwork, and the initial Home shelf window.
- Preserve unchanged media-card DOM, focus, scroll position and decoded artwork during background catalog updates, including alphabet grids.
- Show Plex titles without waiting on slow or missing alphabet data.
- Deduplicate concurrent catalog requests and repeated artwork disk probes.
- Avoid remeasuring offscreen images whenever a download completes.
- Persist an account-scoped, shared collection-discovery index that refreshes in the background.
- Extend regression tests for request sharing, layout, cache correctness and account isolation.

CI validates simulated browser behavior, Chromium 53 compatibility and IPK packaging. Physical LG TV performance still requires hardware testing.
