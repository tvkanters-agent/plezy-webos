# Plezy webOS 1.3.0

- Show both movies and TV series within a collection when Plex libraries have collections sharing the same name (case-insensitive).
- Keep the opened collection first, preserve per-collection ordering, and load additional content incrementally without repeating the same Plex item.
- Continue rendering the original collection when an unrelated library is inaccessible.
- Include regression tests for mixed-library collections, pagination, failures, and on-TV browsing.
