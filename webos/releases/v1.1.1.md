# Plezy webOS 1.1.1

- Album and poster artwork now fades in over 300ms after asynchronous loading. Memory-cached artwork remains immediate.
- Loading artwork shows a clean solid placeholder instead of the browser's white image border; missing and failed artwork uses a subdued fallback icon.
- Alphabet scrollbar is aligned with Plezy, and jumping to a letter retains normal top padding rather than shifting the grid upon return to focus.
- Automated browser tests cover the visual loading state and alphabet scroll/focus regression.

LG TV hardware verification is still pending.
