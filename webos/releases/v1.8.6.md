# Plezy webOS v1.8.6

- Programme Up/Page Up jumps to the next chapter; Programme Down/Page Down restarts the current chapter if more than three seconds have elapsed, otherwise jumps to the previous chapter.
- At the beginning or end of the title, chapter navigation does not wrap around. Without chapters, these keys use the existing timed seek fallback.
- Preserves chapter and audio/subtitle sheet focus while navigating. Includes browser regressions for the LG legacy Page Up/Down key events.

**Compatibility note:** LG currently documents Channel +/- as system-reserved, unavailable to web apps. Legacy LG manuals map Programme +/- to Page Up/Down (33/34), which this release handles when delivered, but some or all LG webOS TV remotes may not send them. A connected keyboard's Page Up/Down is supported. Physical LG hardware behavior remains unverified.
