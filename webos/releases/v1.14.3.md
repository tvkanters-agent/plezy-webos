# Plezy webOS 1.14.3

- Fix a Plex HLS startup error caused by adding a duplicate video target to the Chrome client profile. The video request uses Plezy's Generic profile with a single H.264/AAC MPEG-TS target.
- Request embedded SRT and ASS over Plex Web's independent HTTP subtitle route. This addresses Plex's invalid subtitle-only protocol error and preserves subtitle sync on HLS and Direct Play.
