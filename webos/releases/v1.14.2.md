# Plezy webOS 1.14.2

- Start embedded MKV subtitle extraction after the decoder has opened the video. webOS sends one range request at a time and cancels it when playback changes.
- Keep video playing if the selected MKV subtitle cannot be loaded. If the decoder fails during extraction, retry the same video once using the Plex subtitle endpoint.
- Include the decoder error code or startup timeout if compatibility playback also fails.
