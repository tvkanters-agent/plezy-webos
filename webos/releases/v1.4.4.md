# Plezy webOS v1.4.4

- Fix artwork being discarded or returning revoked URLs when decoded bitmap memory fills. Compressed images now survive bitmap eviction, and protected landing artwork cannot crowd out all new scroll artwork.
- Load saved artwork independently of the two network slots, so cached images do not queue behind slow downloads. Retry persistent downloads after temporary server/network failures.
- Prepare cached destinations before clearing the previous page to prevent blank navigation frames. Saved pages remain usable while fresh server requests run.
- Extend persistent metadata reuse to detail pages, seasons/episodes, collection children and cast filmographies, with background updates.
- Keep Home cached for the session and refresh after restart or invalidation. Back now respects Home invalidation too.

Validated with unit tests, browser navigation/cache regressions, Chromium 53 bundle checks and IPK packaging. Physical LG TV performance still needs hardware verification.
