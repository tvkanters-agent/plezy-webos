Moved diagnostics to a reusable, general setting. Includes the PixiJS subtitle renderer from v1.19.0.

- **Settings → About → Diagnostics → Enable diagnostics** now controls all diagnostics. It is off by default, and takes effect on the next playback.
- Removed the SRT-specific toggle from Video Playback. The on-TV embedded SRT timing panel is the first diagnostic feature using the general switch; future diagnostics can use it too.
- Existing users who enabled the earlier subtitle-specific setting keep diagnostics enabled after updating.
- When the setting is off, no diagnostic clocks, callbacks, counters or on-screen panels run.
