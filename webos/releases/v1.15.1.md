# Plezy webOS 1.15.1

## Fix black video on resume in compatibility mode

- When an MKV with ASS subtitles played audio over a black picture on Resume but worked with Play from beginning, the resume path remained a likely failure point even with Enhanced playback Off.
- Legacy Plex HLS playback now starts without LG's nonzero native start parameter and seeks to the resume position after the first video data is available. This may buffer twice, but leaves the proven working start-from-beginning video path intact.
- Enhanced playback and compatible direct-file fast resumes continue using the existing native start path.

Automated tests verify the source parameters and seek sequencing. The LG TV-specific decoder behavior requires confirmation on the affected hardware.
