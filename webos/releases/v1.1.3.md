# Plezy webOS 1.1.3

Alphabet jumps now retain the grid's small top clearance, without exposing the previous row. Jump placement and D-pad focus use the same geometry, preventing the row from moving when focus returns or moves across it. One Left press returns to the last column of the selected row.

Regression tests cover forward/backward jumps, first-row jumps, focus handoff and subsequent movement in CSS Grid and the TV flex fallback at two viewport widths. Actual LG hardware verification remains outstanding.
