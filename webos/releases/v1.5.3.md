# Plezy webOS v1.5.3

## Fixed

- Switching between Home, libraries, Search and Settings no longer adds duplicate destinations to the Back stack. Back from a top-level tab now returns directly Home, with the existing exit confirmation on the next Back.
- Opening and dismissing a movie, series, season, episode or person page still restores its parent, focus and scroll position.
- Previously visited root pages retain a small bounded session cache for instant redisplay without repeated artwork fades. Libraries revalidate their cached metadata without blocking the UI; Home invalidates after watched-state or playback updates.

## Compatibility

- Preserves the existing webOS 4.x / Chromium 53 frontend and TV D-pad navigation.
