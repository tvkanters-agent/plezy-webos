# Plezy webOS 1.15.2

## Enforce the Enhanced playback switch end to end

- **Off** is now a strict compatibility mode even when a playback caller forgets the setting. It keeps the original Plex playback requests and burned-in subtitles for MKV SRT/ASS, excluding the new Direct Play paths, independent subtitle downloads, Matroska extraction, and custom subtitle rendering.
- The player captures the switch for playback and restarts, prevents background subtitle-recovery retries while Off, and does not read or change subtitle timing. The disabled Subtitle sync row still explains how to enable it when selected.
- The ASS/libass runtime now loads only when Enhanced playback is **On** and an ASS/SSA track actually needs rendering. Switching back to Off removes the custom overlay and its video listeners.
- New API, player and browser regressions assert the Off gate for both MKV SRT and ASS, while confirming the opt-in subtitle path still works.

The double buffer on **Resume** with legacy Plex HLS remains the conservative workaround for the previous black-video regression. Original MP4 direct playback is still available in Off; only *expanded* Direct Play is gated. Real LG hardware playback requires device verification.
