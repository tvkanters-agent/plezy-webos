Fix resume startup buffering on LG webOS.

The previous port loaded the video from the beginning, then changed currentTime,
causing two buffer cycles. This release passes the saved timestamp directly to
LG's native media pipeline through mediaOption before loading the source. Both
direct playback and HLS use this path. The Plex server-offset workaround has
been removed so progress and seeking keep the full-title timeline, as in Plezy.

Install the attached complete IPK. Existing settings and ratings are preserved.

Validation: 88 unit tests, 69 browser tests, Chromium 53 bundle check and IPK
packaging pass. Tests verify the native source contract; actual LG decoder
buffering still needs verification on a TV.
