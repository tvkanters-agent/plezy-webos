## Plezy webOS 1.0.0 — First stable release

Plezy's first stable community port for LG webOS TVs, promoted from the tested 0.2.x series without changing the app ID (`com.tvkdevelopment.plezy`).

### Highlights

- Plex sign-in, server discovery and switching, libraries, collections, playlists, search and TV-remote navigation.
- Movies, shows, seasons and episode detail pages with cast, progress, artwork, ratings and Plezy-inspired controls.
- Direct playback and compatible transcoding with audio/subtitle choice, chapters, intro/credits skipping and resume at the decoder's initial media position.
- Optional Simkl device linking, playback tracking, watched updates and authenticated community ratings, with an included webOS service for catalog lookups.
- Latest 0.2.x fixes: stable playback return without screen flicker, correct native resume loading and cast image placeholders.

### Installation

Download `com.tvkdevelopment.plezy_1.0.0_all.ipk` from this release and install it using LG's webOS Developer Mode tooling. It upgrades previous releases under the same application ID.

The GitHub Actions webOS workflow validates unit tests, browser tests, Chromium 53 compatibility and IPK packaging before publishing. The primary target remains LG webOS 4.4.3 / Chromium 53. This stable designation does not imply feature parity with Plezy's original Flutter app or verification of every TV's decoding, network and live-service behavior.
