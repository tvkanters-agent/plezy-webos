# Plezy webOS v1.8.0

- Chapter sheet now follows Plezy: highlights and focuses the current chapter, shows separate chapter title and timestamp, and includes thumbnail images where Plex provides them.
- Chapter boundaries appear on the player timeline. Previous and next chapter controls and remote media-skip keys use Plezy's chapter traversal, including the three-second previous-chapter rule.
- When an intro or credits skip prompt appears during playback on an LG TV, the button is focused automatically. Pressing OK once skips it, without another step to navigate to the button.
- Focus stays in audio/subtitle/chapter settings when a marker appears behind an open sheet. Existing automatic skip countdown and chapter-marker fallback remain available.

Automated browser and unit tests cover chapter navigation and skip-button focus. Actual LG webOS 4.4.3 remote input and Plex/Jellyfin playback still require hardware verification.
