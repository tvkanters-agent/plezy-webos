# Plezy webOS v1.5.0

- Port Plezy's intro/credits playback markers to webOS, including Plex metadata, nonstandard marker names and safe chapter-title fallback.
- Support Jellyfin's native MediaSegments API with chapter fallback for Jellyfin/Emby when needed.
- Add separate Off / Show skip button / Automatic skip preferences for intros and credits, custom chapter matching and automatic-skip delay.
- Show the native-style floating skip button and countdown during playback, including when transport controls are hidden. Preserve remote focus, cancellation and inactivity dismissal; handle credits ending at EOF correctly.
- Add marker unit and playback browser tests, with Chromium 53 bundle and IPK packaging checks.

CI verifies parser and browser behavior; actual LG webOS decoder and remote interactions still require hardware verification.
