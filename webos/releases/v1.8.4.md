# Plezy webOS v1.8.4

- Intro detection from chapter titles now recognizes **Logo** and **Logos** as well as Introduction, Intro, Opening and OP. For example, a chapter titled "Studio Logos" offers Skip Intro.
- Adjacent intro chapters (such as **Studio Logos** immediately followed by **Opening**) are combined into one skip action, so a single click jumps past both.
- Native Plex intro markers still take precedence. Explicitly customized intro regexes and the existing false-positive safeguards remain unchanged.
- Adds Plex, Jellyfin and playback regression tests for the new default pattern.

Automated tests validate the chapter fallback in Chromium and Node. Actual LG hardware playback remains to be verified.
