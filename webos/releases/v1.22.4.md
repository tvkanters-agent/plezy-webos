Reduce ASS subtitle startup delays, intermittent invisible subtitles, flicker and post-seek timing drift.

- Prevent the SubtitlesOctopus wrapper from sending competing, uncorrected video clock messages while enhanced ASS playback is active. Its sizing and metadata callbacks still operate normally.
- Apply playback rate and paused/seeking state before each libass clock timestamp to eliminate one-frame updates from stale playback state.
- Only append incremental ASS events after the worker has actually finished initializing the subtitle track and styles. Reuse its style response rather than issuing an early duplicate worker request.
- Start embedded ASS extraction as soon as a decoded frame is confirmed, including paused playback and hardware decoders that report zero video dimensions. Remove ASS's additional 200 ms startup timer while keeping the native resume/first-frame guard.
- Load independent legacy libass worker script chunks in limited parallel batches while preserving their original order.
- Detect the libass first painted subtitle frame directly from its image payload, rather than sampling a low-resolution canvas that could miss thin signs and hide otherwise rendered subtitles.
- Add focused regression tests for worker readiness, clock ownership, paused opening, zero-dimension startup and tiny-sign visibility.
