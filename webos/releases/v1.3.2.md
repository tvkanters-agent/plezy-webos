# Plezy webOS 1.3.2

- Load recently visited Home and library content from a short-lived in-memory catalog cache, avoiding redundant server round-trips.
- Cover recommended shelves, Browse pages (including alphabet changes), collections and playlists. Coalesce overlapping requests.
- Limit cached metadata to 32 entries for 45 seconds; never persist user-specific catalog data across launches.
- Refresh after playback, watched-state changes, server/account changes, and explicit Refresh.
- Retain existing first-frame artwork hydration, playback, sidebar focus, and alphabetical pagination behavior.
- Verified in GitHub Actions unit tests, browser regressions, legacy Chromium compatibility checks, and IPK packaging. LG hardware remains untested.
