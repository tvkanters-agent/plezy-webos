# Plezy webOS v1.10.3

Fix video playback remaining stalled after seeking and correct subtitle-sync Reset icon alignment.

- Seeking previews the new timestamp and thumbnail without pausing or buffering before OK.
- After OK, Play is requested immediately when needed, and the recovery logic waits for actual playback-time progression instead of mistaking a decoded-but-stuck state for success.
- Handles paused decoders, unresolved Play promises, and a frozen clock after buffering while preserving user Pause and Back.
- Reset button now uses a properly centered vector icon in the compact Plezy sync bar.

Subtitle sync offset behavior remains unchanged in this patch.
