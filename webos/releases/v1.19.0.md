SRT/VTT subtitles in Enhanced playback now use PixiJS 4.8.9 instead of Media Captions' HTML cue painting and the custom SVG border.

- Sharper, more even subtitle outlines: Pixi text textures render at twice the output resolution, with rounded stroke joins and the fill painted on top.
- Connected to the existing Subtitle Styling settings: size, colors, border size/color, position, margins, bold and italic. Inline bold/italic and multiline SRT text continue to work.
- Cue changes and subtitle sync updates don't trigger full text rasterization on each frame.
- Pixi loads only when enhanced text subtitles are selected. Compatibility playback, optional subtitle diagnostics and ASS/SSA styling remain unchanged.

Tested with browser/unit regression coverage. The exact appearance and performance still need checking on the LG OLED C8.
