# Plezy webOS 1.11.4

- Preserve unchanged episode rows, artwork and remote focus during catalog refreshes.
- Update visible season/show children and cached pages after watched/unwatched actions.
- Keep rapid audio/subtitle selections, playback position and paused state through decoder restarts.
- Accept successful Plex track updates with XML responses; reject HTTP errors normally.
- Isolate subtitle offsets by server/account and prevent stale episode launch requests.

Validated through GitHub Actions unit/browser/Chromium 53 bundle and IPK checks. Hardware LG playback remains unverified. Old unscoped subtitle offsets are discarded to avoid applying another server's offset.
