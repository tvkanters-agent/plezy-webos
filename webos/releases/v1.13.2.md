# Plezy webOS 1.13.2

- Read indexed embedded SRT and ASS from the original MKV using Plex byte ranges. The offset slider no longer depends on Plex's separate subtitle endpoint for these files.
- Only the subtitle index and the required blocks are read. The original video route continues independently.
- Verify rendered SRT and ASS timing against a real MKV fixture with the separate subtitle endpoint unavailable.

Local extraction requires HTTP byte ranges and an index for the selected track. Plex extraction and burn-in remain fallbacks. Physical LG playback remains unverified.
