## CI and QA improvements

- Run unit tests, Chromium 53 bundle/IPK packaging, and two Playwright browser shards in parallel.
- Eliminate duplicate branch/PR CI runs and cancel obsolete PR checks without interrupting master.
- Run applicable browser tests for isolated feature changes, falling back to full E2E for shared/unknown changes and on master.
- Preserve the final test-and-package gate and selector regression coverage.

No application behavior changes; LG hardware testing remains separate.
