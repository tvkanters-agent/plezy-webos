# Plezy webOS 1.2.0

- Persist Plex and Jellyfin/Emby poster artwork, episode thumbnails and detail backdrops in an 80 MiB / 500-entry IndexedDB LRU cache with seven-day expiry and automatic quota-pressure eviction.
- Retain a bounded collection of recently decoded images in memory, so navigating back to artwork already on screen renders it on the first frame without a placeholder or repeat download.
- Fade in artwork that was not available for the initial frame, including actor portraits and detail backdrops. Cast photos are not persisted.
- Preserve the existing viewport-aware two-image concurrency limit, poster placeholders and failure fallback. Unsupported IndexedDB, failed cross-origin image fetches and oversized artwork fall back to normal image loading.
- Add unit and browser regression tests for memory reuse, expiration, network request deduplication, persistent cache reuse after restarting, and cast-photo fade-in.

The cache is best effort on older LG webOS/Chromium engines. Live-TV testing is still needed to verify device-specific storage quotas and cross-origin behavior.
