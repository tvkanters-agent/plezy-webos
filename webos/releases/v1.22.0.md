Faster repeat ASS playback and more reliable subtitle timing:

- Reuse the initialized libass worker and registered fonts across repeat plays and sibling episodes using identical fonts. Suspend all worker video listeners when not rendering ASS.
- Store completed embedded ASS tracks so reopening the same Plex part avoids MKV subtitle index/cluster network reads, including after restarting Plezy.
- Correct pauses, seeks and buffering by synchronizing libass to the actual video clock and repainting paused seek positions.
- Wait for the renderer's actual runtime-ready signal instead of a preliminary worker message.

Both custom subtitle modes remain opt-in. Browser and unit tests cover replay, episode switching, caching and seeking. Real-world latency and synchronization still need verification on LG webOS 4.4.3.
