Fixes two SRT subtitle-styling issues reported after v1.17.0:

- Border Size now produces a uniform contour around the whole glyph instead of an uneven, faint text-shadow approximation. Stroke width scales with the number setting and screen height, including zero for no border.
- Numeric dialogs keep stable TV remote focus when changing values with Left/Right. Down reaches Save, Left/Right traverses Cancel and Save, and Up always returns to the number; Back still cancels.

This is a webOS renderer and D-pad fix. ASS/SSA subtitles and Plex burn-in remain unchanged. Automated browser tests include simulated keyboard focus and rendered styles; visual behavior on a physical LG TV is not yet verified.
