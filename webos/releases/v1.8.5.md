# Plezy webOS v1.8.5

- Intro detection from chapter titles now recognizes **Logo** and **Logos** as well as Introduction, Intro, Opening and OP. A chapter titled "Studio Logos" offers Skip Intro.
- Adjacent intro chapters (such as **Studio Logos** immediately followed by **Opening**) are combined into one skip action, so a single click jumps past both.
- Native Plex intro markers still take precedence. Explicitly customized intro regexes and the existing false-positive safeguards remain unchanged.
- Adds Plex, Jellyfin and browser regression tests for this behavior.

Automated tests validate chapter fallback and combined skipping. Actual LG hardware playback remains to be verified.
